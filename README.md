# 적벽전설

삼국지 인물 27종과 진영별 고정 20장 덱으로 처음부터 승패까지 플레이하는
오프라인 1:1 카드 대전입니다. 첫 실행에서 위·촉·오·이민족 지휘관을
선택하며, 각 지휘관은 고유 능력을 가집니다. 화면, 카드 초상, 문양,
파티클과 효과음은 외부 에셋 없이 Canvas 2D와 Web Audio API로 절차
생성합니다.

## 실행

Node.js 22 이상에서:

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

배포용 빌드와 전체 회귀 테스트:

```bash
npm test
```

## 조작

- 첫 화면에서 조조·유비·손권·맹획 중 지휘관과 고정 진영 덱 선택
- 손패나 전장 카드를 클릭하면 큰 카드 상세 설명을 고정 표시
- 손패를 전장으로 드래그하거나, 카드 선택 후 전장을 다시 누르면 출전
- 대상 지정 카드는 선택 후 빛나는 영웅 또는 장수를 선택
- 공격 가능한 아군을 선택하고 적 영웅/장수를 선택
- 지휘관 능력 문양을 눌러 턴당 한 번의 능력을 사용
- 맹획의 대상형 능력은 문양 선택 후 빛나는 적 장수를 선택
- `Enter`/`Space`: 키보드 선택 실행
- `Esc`: 상세 설명과 선택 취소
- `M`: 음소거

## 구조

`public/systems/*`의 6개 시스템은 서로 파일을 import하지 않습니다.
각 시스템은 `globalThis.TK.modules`에 팩토리만 등록하며, 메인 런타임이
전달하는 컨텍스트로만 협력합니다.

- `rules-engine`: 턴, 자원, 지휘관 능력, 효과, 전투, 승패
- `card-data`: 카드 27종, 토큰 2종, 진영별 고정 20장 덱
- `board-ui`: Canvas 보드와 포인터/키보드 조작
- `opponent-ai`: 시뮬레이션 기반 전략 휴리스틱
- `fx-animation`: 파티클과 전투 애니메이션
- `audio`: Web Audio 절차 합성
