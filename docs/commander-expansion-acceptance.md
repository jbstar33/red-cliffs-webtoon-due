# 4진영·지휘관·27장 확장 검수 기록

## 완료 범위

- 최초 실행 시 `위 / 촉 / 오 / 이민족` 가운데 진영과 지휘관 선택
- 선택한 진영 중심의 고정 20장 덱으로 단일 PvE 한 판 완주
- 조조: 비용 1, 지휘관 체력 1 회복
- 유비: 시작 시 반사 2, 영웅을 공격한 적에게 피해 1
- 손권: 비용 3, 모든 적 캐릭터에게 피해 1을 주는 수공
- 맹획: 비용 2, 지정한 적 장수의 다음 공격 1회 봉쇄
- 플레이 가능한 장수 27장과 토큰 2종
- 외부 이미지·폰트·음원 없이 Canvas, SVG, Web Audio API로 생성

- 최초 선택 화면에서 네 지휘관의 비용·효과를 선택 전에 모두 읽을 수 있음

- 손권 수공을 적 영웅과 복수 장수가 있는 실전 전장에서 발동해 동시 피해·사망·드로우를 확인
