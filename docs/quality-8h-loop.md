# 적벽전설 8시간 품질 개선 루프

## 범위 고정

- 카드 19장, 20장 덱
- 플레이어 대 AI 단일 PvE
- 외부 이미지·폰트·사운드 파일 없음
- Canvas 절차적 일러스트와 Web Audio만 사용

## 비교 기준

하스스톤을 복제하지 않고 다음 플레이 경험 원칙만 기준으로 삼는다.

1. 작은 손패에서도 비용, 이름, 공격력, 체력이 즉시 구분된다.
2. 카드를 확대하면 발동 시점, 대상, 수치, 결과를 한 번에 예측할 수 있다.
3. 반복 키워드는 짧게 쓰되 즉시 평문 정의를 확인할 수 있다.
4. 장수는 이름을 가려도 실루엣, 무기, 자세, 배경 사건으로 구분된다.
5. 카드 선택, 출전, 공격, 피해, 사망에 각각 다른 시각·음향 피드백이 있다.
6. 한 턴의 유효 선택지가 둘 이상이며, 명백한 단일 정답이 반복되지 않는다.

## 기준 화면 진단

- 능력: `돌진.`처럼 키워드만 표시되어 실제 규칙을 추론해야 한다.
- 상세: 능력과 키워드가 중복되고 키워드 정의가 없다.
- 일러스트: 인물별 관모와 무기는 다르지만 정면 흉상과 굵은 외곽선이 반복된다.
- 구도: 배경 사건과 동작이 약해 카드 전략 게임의 수집·감상 만족도가 낮다.
- 손패: 카드 본문은 작아 클릭 상세에 지나치게 의존한다.
