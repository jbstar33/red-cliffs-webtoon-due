# 카드 데이터

브라우저에서 `index.js`를 로드하면 `globalThis.TK.modules.cardData`에
등록된다. 다른 시스템을 가져오지 않고 통합 계약의 DSL만 사용한다.

## 구성

- 정규 카드 50장: 촉 12장, 위 12장, 오 12장, 남만 10장, 군웅 4장
- 토큰 2종: 손권의 `강동 수군`, 목록대왕의 `남만 맹수`
- `buildDeck(seed)`: 종전 호출과 호환되는 20장 혼성 덱
- `buildDeck(seed, faction)`: 선택 진영 고정 레시피를 시드로 섞은 정확히
  20장의 카드 ID 배열. 비용 1~2 카드 10장과 비용 3 이상 카드 10장으로
  구성해 한 비용대에 치우치지 않음
- `getDeckRecipes()`: UI 미리보기와 검수를 위한 방어적 복사본
- `getKeywordGlossary()`: 돌진·수호·방패의 완전한 규칙 설명
- `auditBalance(sampleSize)`: 카드별 비용 대비 추정 전투 가치와 덱 곡선 감사

## 진영 덱 계약

| 지휘관 입력 | 정규화 진영 | 선택 진영 카드 | 평균 비용 |
| --- | --- | ---: | ---: |
| `caocao`, `조조`, `wei`, `위` | 위 | 12/20 | 2.60 |
| `liubei`, `유비`, `shu`, `촉` | 촉 | 12/20 | 3.05 |
| `sunquan`, `손권`, `wu`, `오` | 오 | 12/20 | 2.45 |
| `nomad`, `이민족`, `nanman`, `남만` | 남만 | 10/20 | 2.90 |

알 수 없거나 생략된 진영 입력은 기존 혼성 덱으로 안전하게 폴백한다.
레시피 순서는 고정되어 있고 셔플만 `seed + 정규화 진영`에 의해
결정되므로 같은 두 인자를 주면 언제나 같은 덱 순서가 나온다.
규칙 엔진은 셔플 후 양쪽 시작 손패 4장에 비용 1~2 카드가 1~2장만
포함되도록 덱 상단을 조정한다. 저비용 카드만 잡히거나 초반 선택지가
전혀 없는 시작을 함께 방지한다.

## 명확한 카드 텍스트

표시 문구는 직접 작성한 별도 문자열이 아니라 `keywords`, `target`,
`abilities` DSL에서 생성한다. 따라서 실제 발동 효과와 수치가 어긋날 수
없다.

- `summaryText`: 손패용 축약 문구. 평균 18.5자, 최대 44자
- `text`: 클릭 상세용 완전한 규칙 문구. 평균 46.9자, 최대 100자
- `출전:`: 손패에서 전장에 낼 때 발동
- `유언:`: 하수인이 죽어 전장에서 사라질 때 발동
- `돌진 — 이 하수인은 출전한 턴에도 공격할 수 있습니다.`
- `수호 — 적은 수호 하수인이 하나라도 있으면 수호 하수인만 공격할 수 있습니다.`
- `방패 — 이 하수인이 처음 받는 피해를 한 번 전부 막습니다.`
- 선택 피해는 카드 소유자가 고른 `적 캐릭터` 한 명이며, 적 영웅과 적 하수인을 모두 뜻함을 문장에 명시
- 전체 아군 강화는 출전한 하수인 자신도 포함함을 명시
- 무작위 적 피해는 적 하수인이 없을 때 적 영웅에게 들어가는 예외까지 명시
- 토큰 소환은 5칸 전장의 빈자리만 사용하며 최대 소환 수까지 명시
- 비용 감소는 비용 1 이상 손패만 대상으로 하며 최소 0과 대상 없음 불발을 명시
- 재공격은 이전 턴부터 있던, 이번 턴 공격을 마친 다른 아군만 대상으로 하며 대상 없음 불발까지 명시

각 카드의 `tactics`에는 서로 중복되지 않는 `identity`, `plan`, `combo`,
`counter`가 있다. UI는 필요할 때 이 정보를 상세 설명에 바로 사용할 수
있다.

## 자체 검증

```sh
node public/systems/card-data/test.mjs
```

검증 항목:

- 50장 전체와 토큰 2종의 효과 DSL·표시 문구 계약
- 신규 카드의 비용·공격력·체력·키워드·대상·발동 효과 스냅샷
- 신규 장수별 구도·갑주·표정·조명까지 포함한 확장 초상화 메타데이터
- 키워드 정의와 출전·유언 발동 시점 누락
- 타깃 종류, 수치 범위, 지원하지 않는 효과
- 소환 그래프 순환과 무한 발동 가능성
- 50개 전술 정체성의 중복
- 상세 텍스트 120자, 손패 요약 44자 가독성 한도
- 선택·모든·무작위·다른·이번 턴·최대·불발 판정어와 실제 규칙의 일치
- 전술·콤보·대응 설명에 방패, 방어도, 무작위 대상의 실제 동작과 다른 조언이 없는지 검사
- 기본 덱과 4개 진영 덱을 1,000개 시드로 반복한 20장 구성, 최대 2장,
  진영 강조, 카드 풀 커버리지와 저비용 10장·중고비용 10장 곡선
- 256개 셔플 시드에서 양쪽 시작 손패의 저비용 카드가 1~2장인지 검사
- 10,000개 덱 시드의 초반 플레이 가능성과 평균 비용
- 비용 대비 추정 전투 가치 0.75~1.45 범위와 단일 카드 즉발 피해 상한
