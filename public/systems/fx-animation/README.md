# FX Animation

브라우저 전역에 `globalThis.TK.modules.fxAnimation.createFX`를 등록하는 독립
Canvas2D 연출 모듈이다. 다른 시스템 파일을 import하지 않으며 위치 정보는
생성 시 전달되는 `getAnchor` 콜백으로만 얻는다.

지원 연출:

- 출전·공격·피해·사망의 `예고 → 충돌 → 잔향` 3단 타이밍
- 진영색 장수 표식의 곡선 돌진, 근원→대상 광원 궤적, 최대 22px 오버슈트
- 접촉 순간의 압축 타원·반동파·국소 보드 광원과 피해 숫자
- 치유·피해·강화·패 보충·독·수호·계략의 고유 색·문양·한국어 라벨
- 지휘관 전용 피드백:
  - 조조 `commander:power`: 청백 회복 룬과 짧은 상향 기류
  - 유비 `commander:reflect`: 유비 영웅에서 공격자 앵커로 역류하는 금빛 반사선
  - 손권 `commander:power`: 적 전장 아래를 가로지르는 청록 수공과 영웅·장수별 물보라
  - 유목 군주 `commander:lock`: 대상 장수에 조여드는 황갈색 올가미와 봉인 매듭
- 진형·연계·고유 행동 피드백(각 0.8초 이하):
  - `formation:place`: 전열은 주황, 후열은 청색 착지 인장
  - `formation:block`: 보호 대상 앵커의 철제 전열 장벽과 잠금 문양
  - `faction:link`: 의형제·군략·연화·약탈별 색과 맞물린 고리
  - `duel:start`, `duel:hit`: 두 앵커를 잇는 교차 검로와 승부 충돌
  - `status:burn`, `status:counter`, `status:intimidate`, `status:empty-fort`,
    `status:raid`: 불꽃·역회전 반계·호통 파동·빈 성문·약탈 올가미
- 방패 균열과 파편, 수호 문장, 사망 먹구름·파편·먹 얼룩·균열 잔상
- 카드가 패로 날아드는 드로우와 패 소각 피드백
- 턴 시작 먹선 현수막, 전투 뒤 0.9초 지연되는 1.12초 승리·패배 안무
- 잘못된 행동 피드백

승패 제목·설명·암막·재시작 조작은 보드 UI가 단독 소유한다. FX의 `game:end`
처리는 텍스트 없이 승리 월계·광륜·짧은 색종이 또는 패배 균열·먹 장막·재를
그린다. 모든 승패 파티클도 1.2초 안에 정리된다. `blockedByGuard` 실패는
일반 오류 대신 첫 수호 대상을 강조한다.
동일한 `source + op + target`의 `effect:trigger`는 100ms 동안 합쳐 소환 연출이
겹치지 않게 하며, 실제 대상 인덱스가 다르면 각각 유지한다.
유목 군주의 `commander:power` 직후 발행되는 `commander:lock`이 올가미 연출을
단독 소유하므로 동일한 봉쇄 피드백이 두 번 생성되지 않는다.

모든 파티클은 420개 고정 풀을 재사용하고 타임라인은 72개로 제한한다.
`prefers-reduced-motion` 또는 `reducedMotion` 옵션에서는 흔들림을 제거하고
이동 애니메이션 대신 짧은 정적 문장과 라벨을 표시한다. 신규 전술 연출은
감소 모션에서 파티클도 만들지 않으며 모든 타임라인이 0.35초 이하로 줄어든다.

`hasActiveVisuals()`는 렌더러가 다음 프레임에도 화면을 바꿀 수 있는지를
O(1)로 반환한다. 지연 중인 타임라인, 살아 있는 파티클, 아직 끝나지 않은
흔들림을 포함하며 완전 유휴 또는 `destroy()` 이후에는 `false`다. 게임
런타임은 이 공개 신호가 `false`인 동안 FX 캔버스 갱신을 건너뛸 수 있다.

독립 검수 무대는 `mock.html`을 열어 사용할 수 있다. 각 버튼은 하나의
이벤트 계약만 호출하며 조조 회복, 유비 반사, 손권 수공, 유목 봉쇄 버튼도
포함하므로 타 시스템 없이 타이밍과 시각 언어를 확인할 수 있다.

로컬 검증:

```sh
node --check index.js
node test.cjs
```
